# Documentation

CopyLocker is a licensing and anti-tamper toolkit for software vendors. The documentation is
organized in three sections:

- **Guide** — start with [What is CopyLocker](/docs/guide), then the
  [5-Minute Quickstart](/docs/guide/quickstart), [Protection Levels](/docs/guide/protection-levels),
  [the Licensing Model](/docs/guide/licensing-model), the [Web SDK](/docs/guide/web-sdk),
  [Deployment](/docs/guide/deployment), [Migration](/docs/guide/migration), and the
  [FAQ](/docs/guide/faq).
- **Security** — the [Security & Threat Model](/docs/security/threat-model), the public security
  contract including the residual-risk list.
- **Operations** — the [Runbook](/docs/operations/runbook), [SLOs & Alerting](/docs/operations/slo),
  and [Cost Estimation](/docs/operations/cost-estimation).
